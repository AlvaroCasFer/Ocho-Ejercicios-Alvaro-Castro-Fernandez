26 de octubre de 2026

Windows fue originalmente desarrollado como un entorno de escritorio para el sistema operativo MS-DOS.

Por ejemplo, si querias iniciar windows 1.0, tenias que ejecutar el comando "win" desde el prompt de DOS.

Versiones como windows 95 y windows 98 mantuvieron esta relación con MS-DOS teniendo que cargar el sistema operativo antes de poder ejecutar Windows.

No fue hasta windows XP (2001) que dejo de tener relacion con el sistema operativo MS-DOS.

Dato extra

Windows originalmente se llamo asi por una estrategia de marketing, debido a que el nombre inicial (inteface manager) resulto ser poco atractivo.
